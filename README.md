Проект "Solar Tales" - Информационно-справочная консольная система направленная на работу и обработку информации космических тел.

Обьекты: Планеты и Спутники.

Функции системы: 
1) Добавление данных.
2) Просмотр данных.
3) Удаление данных.
4) Поиск данных.
5) Сортировка данных.
6) Сохранение данных и выход из системы.

↓ Дополнение к программе ко второму экзамену: ↓

7) + сортировка планет по планетам земной группы
   + сортировка планет по планетам гигантам
   + сортировка планет по планетам карликам
8) Внедрение в проект принципов ООП (изменение кода с его соответстивями)
   + Инкапсуляция (геттеры и сеттеры)
   + Наследование (спутники могут наследовать данные от планет)
   + Полиморфизм (спутники могут реализовывать метод присвоение ему типа планеты в пустую null, из за полиморфизма)
   + Абстракция (во всех методах)
